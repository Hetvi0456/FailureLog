# FailureLog

A personal debugging memory system for developers.

## Problem Statement

Developers frequently encounter errors, test multiple potential fixes, and eventually resolve them—only to forget what worked when a similar error recurs later. This results in wasted time debugging the same or similar problems from scratch.

## MVP Features

1. **Authentication**: User Login and Registration.
2. **Dashboard**: Centralized overview of recorded failures and quick stats.
3. **Failure Management**: Create, View, Edit, and Delete failure entries.
4. **Debugging Log**: Record step-by-step debugging attempts for each failure.
5. **Resolution Tracking**: Mark failures as resolved with root cause and final solution.
6. **Search & Filter**: Search and filter failures by title, project, technology, category, status, etc.
7. **Basic Statistics**: Overview of resolution rates and failure metrics.
